数采网关 · 标准化实施

现场实施手册

本手册规定数采网关从现场调研、采集点位整理、安装接线到配置导入与验收的标准作业流程，适用于实施人员及参与调研的现场人员。每台网关对应一台被采集设备；网关出厂时统一烧录固件，现场接入的设备及采集内容均由《设备数采现场调研表》确定，无需修改程序。

适用固件：配置页“采集”含“下载调研表模板”的网关固件 配套文件：现场调研.html、设备数采现场调研表.xlsx 版本：2026-11-04

0实施流程概述

每个工厂使用一份调研表：第 1 步由现场人员在“现场调研页面”中完成并导出调研表，第 2、3 步由实施人员在 Excel 中补全；第 4~6 步在现场按每台网关逐一执行。

角色职责能力要求
现场人员第 1 步：使用现场调研页面录入设备并导出调研表，拍摄铭牌及电柜照片，向设备厂商索取 PLC 点位表熟悉现场设备，能识读设备铭牌
设备厂商提供设备的 PLC 点位表（地址表），通常为整台设备的全部点位—
实施人员第 2 步：筛选并录入采集点位；第 3 步：填写实施配置；第 4~6 步：现场安装、配置导入与验收具备接线能力，熟悉浏览器操作；持有厂家账号

—实施准备

资料

  • 现场调研页面 现场调研.html：离线页面，复制到手机或电脑后用浏览器直接打开，无需联网
  • 空白调研表模板（实施人员备用）：在任一网关配置页“采集”中点击“下载调研表模板”获取，或使用研发提供的 设备数采现场调研表-模板.xlsx
  • 厂家账号：用户名 factory，密码向研发负责人申请；密码不得写入调研表
  • 上位机地址及端口：向上位机负责人确认

工具

  • 笔记本电脑，安装新版 Chrome 或 Edge 浏览器
  • 手机：打开现场调研页面，拍摄铭牌及电柜
  • 网关及电源；按设备通讯接口准备 RS485 双绞线、RS232 线缆或网线
  • 一字螺丝刀、扎带

1设备调研

责任人：现场人员

现场人员使用现场调研页面（现场调研.html）逐台录入设备。除设备名称、资产编号外，各项均以点选或下拉选择完成，照片在设备编辑页直接拍摄并与该设备绑定；同型号设备在编辑页点击“复制为新设备”，仅需修改名称和编号。录入内容自动保存在本机浏览器中。

调研完成后点击“导出调研资料”：有照片或资料时生成资料包 设备数采现场调研资料-工厂名称-日期.zip，内含调研表（.xlsx）及“照片 /”“资料 /”目录，文件按“资产编号-类型-序号”命名（如 AMAJQ0221-铭牌-1.jpg），调研表“照片 / 资料”列自动列出对应文件名；无照片时直接生成调研表 .xlsx。资料提交实施人员，解压后使用其中的 .xlsx 导入网关。调研表“设备清单”工作表中，现场录入内容位于左侧蓝色、绿色、橙色区域，“设备类别”按设备类型和控制器品牌自动换算，“通信协议”按控制器品牌和通讯口自动生成，“实施状态”按调研结果自动标记；右侧紫色“实施配置”区域由实施人员填写。需修改时，在页面中点击“打开调研资料”选择已导出的 .zip 或 .xlsx 文件，照片按资产编号归回各设备，实施人员已填写的内容将保留。

录入说明

项目录入要求
设备名称 *填写现场通用名称，如“1# 高速冲床”。该名称仅用于配置网页及上位机界面显示。
资产编号 *填写设备铭牌编号或固定资产编号，全厂唯一，仅限字母、数字及 - _ .。上位机以此编号区分设备，更换网关时保持不变。
设备类型 *下拉选择，按金属成形、机械加工、塑料与橡胶、焊接、装配与包装、表面处理与热处理、检测与试验、动力与公用、仪表分组；列表以外的选择“其他（手动填写）”。网关使用的“设备类别”（PLC 控制设备、数控机床 / 工控机设备、注塑机、仪表 / 测试仪、自研控制板设备、无控制器设备）由页面自动换算。
厂商配合“需厂商提供 / 配合”勾选数据采集需设备厂商提供的资料或配合事项，可多选：PLC 点位表、通讯协议文档、开放通讯权限 / 解除加密、开放数据接口（数据库 / OPC UA / Modbus TCP）、数控系统通讯选项授权、修改 PLC 程序、通讯扩展模块、通讯参数、电气图纸、现场配合调试；列表以外的事项在“其他”中录入。页面按控制器品牌以虚线框标出建议项：PLC 设备通常需要点位表，工控机通常需要开放数据接口和协议文档，自研控制器通常需要协议文档和现场配合调试。“厂商配合情况”点选“已提供 / 已同意 / 需付费 / 不配合 / 待沟通”。厂商的配合情况是判断该设备能否采集的前提；设备厂家、型号、联系人依据铭牌及采购资料填写。
控制器品牌、型号以电柜内 PLC 或触摸屏的铭牌为准，下拉选择。选择品牌后列出该品牌常见型号，列表中没有的型号选择“其他（手动填写）”按铭牌录入。无法确认时选择“未知”，并附照片供实施人员判断。
预留通讯口点选控制器上可用于数据采集的通讯接口，识别方法见图 2。无法确认时选择“未知”。
现场网络点选设备安装位置的网络条件：有线网络 / 无线网络 / 无网络。
照片与资料在设备编辑页按“铭牌 / 电柜 / 通讯口 / 其他照片 / 厂商资料”分类点击“＋”，直接拍摄或从相册、文件中选择。每台设备应至少拍摄设备铭牌、电柜内控制器、通讯接口特写各一张。照片自动压缩至长边 2048 像素，导出时按“资产编号-类型-序号”命名。
是否采集点选“是 / 否 / 待定”，默认为“是”。选择“否”的设备在导入时不予列出。
需要采集的数据勾选需求项（产量 / 计数、运行 / 停机状态、报警等，可多选），列表以外的需求在“其他需求”中录入。无需填写协议或地址。

通讯接口识别

注信息无法确认时，应选择“未知”或留空，不得估填。实施人员将依据照片及厂商资料补充。

2采集点位整理

资料来源：设备厂商 PLC 点位表责任人：实施人员

设备厂商通常提供整台设备的 PLC 点位表（又称地址表、变量表、通讯表），包含数百至上千个点位，格式包括 Excel、PDF、截图或 PLC 程序导出的注释等。实施人员依据设备清单中“需要采集的数据”，从点位表中筛选对应点位，逐行录入调研表的“采集点位”工作表。

点位表索取要求

应在第 1 步调研时向设备厂商索取该设备的 PLC 点位表，并要求注明各地址的含义及数据类型（字、双字、浮点）。点位表文件名记录于设备清单“照片 / 资料”列，与照片一并归档。

点位查找方法

采集需求点位表检索关键词常见地址与类型
产量、次数产量、计数、累计、总数、件数、次数、count、totalD / DM / V 区，多为双字整数
运行状态运行、自动、启动、运转、run、autoM / X / Y / CIO 位，开关量
报警报警、故障、异常、急停、alarm、error、faultM 位，开关量；或为报警代码（整数）
温度、压力等工艺参数温度、压力、速度、转速、电流D / DM 区，整数或浮点数；须确认倍率（如 ×0.1）
出处记录每个点位应在“厂商点表出处”列注明点位表中的原名称或页码，如“冲压计数 D200（第 3 页）”，以便数据核对时追溯。无法确定的点位应予以标注，向厂商确认，并在验收时与设备显示值比对。

同型号设备共用点位

同一厂家、同一型号的设备，点位表通常相同。此类设备的点位只录入一份，并指定一个点表名称；在设备清单中为这些设备填写相同的“点表名称”。未填写点表名称的设备，按资产编号对应点位。

地址书写规则

按厂商资料的写法填写“区名 + 编号”，不区分大小写。

控制器写法示例说明
三菱 FXD200　M10　X17　Y7X、Y 为八进制编号（不含数字 8、9），按资料原样填写
欧姆龙DM8101　CIO100.00小数点后为位号 00~15
西门子 S7-200V100　VW100　VD100　V10.3　I0.1　Q0.0　M2.5VW、VD 均按 V 区处理；小数点后为位号 0~7
Modbus 设备40001　30001　00001　10001首位 4 为保持寄存器、3 为输入寄存器、0 为线圈、1 为离散输入；取寄存器中的某一位写作 40001.3

数据类型选择

数据类型适用条件示例
开关量 0/1仅有两种状态；地址为 M、X、Y、CIO、I、Q 或带“.位号”运行 / 停止、报警
整数占一个字（D / DM / V），可能为负数温度 -20
无符号整数占一个字，非负，最大 65535模式选择、状态码
双字整数占两个字（如 D200、D201），数值可能超过 65535累计产量、冲压次数
浮点数带小数，占两个字；厂商资料标注为 REAL / FLOAT压力 0.62
BCD 码厂商资料标注为 BCD；设定值 1234 以十六进制 1234 存储检测时间
倍率与小数位寄存器值为 1234、实际值为 123.4 rpm 时，倍率填写 0.1，小数位填写 1。上报值 = 读数 × 倍率。
上报方式“周期上报”在每个采集周期均上报，适用于压力、温度等参数；“变化上报”仅在数值变化时上报，适用于计数、状态类数据，可显著减少报文量。
字符限制“单位”将写入上报报文，仅限英文字母、数字及英文符号，如 MPa、C、rpm；不得使用“℃”“转/分”等中文或特殊符号。

录入完成后自查

  • “需要采集的数据”中的每一项均有对应点位，或已注明无法找到
  • 每个点位均填写编号、名称、地址、数据类型；同一设备内编号不重复
  • 单位仅使用英文字符
  • 同型号设备只录入一份点位，且已在设备清单中填写相同的“点表名称”

3实施配置

责任人：实施人员

在“设备清单”右侧紫色“实施配置”区域填写以下内容。未填写的参数由网关按协议默认值处理。

项目录入要求
网关编号计划安装于该设备的网关编号，见网关标签（如 JXGS001）。导入时将据此自动选中该设备。
点表名称同型号设备填写相同名称（见第 2 步）；为空时按资产编号对应点位。
通信协议按“控制器品牌 + 预留通讯口”自动生成，规则见下表。品牌不在规则内或通讯口为“未知”时，从下拉列表中手动选择。
通讯参数串口设备填写，格式为“波特率 数据位校验位停止位”，如 9600 7E1，须与 PLC 设置一致。参数不明确时向设备厂商确认，或留空采用协议默认值。
站号PLC 站号或从站地址；为空时采用协议默认值（见附录）。
设备 IP、设备端口网口设备必须填写设备 IP；端口为空时采用协议默认值。
网关 IP网关使用固定 IP 时填写；为空时自动获取。
采集周期 ms两轮采集之间的间隔，默认 1000（1 秒）。
上报方式逐点（默认）：每个点位单独上报；批量：每轮采集结果合并为一条报文。按上位机要求选择。
设备类型 ID、订单名称按上位机约定填写英文字符，如 LM。
实施状态待调研、待厂商资料、待实施、已上线、不实施，用于跟踪实施进度。

上位机与网络

“上位机与网络”工作表全厂通用，填写一次即可：上位机地址及各端口；网关使用固定 IP 时，另填子网掩码与默认网关。留空的项目保持网关原有设置。

保存要求填写完成后须在 Excel（或 WPS）中保存。“通信协议”由公式生成，未经保存的文件导入时该项为空。

4安装与接线

责任人：实施人员

每台网关连接一台设备。接线须在断电状态下进行，完成后再上电。串口设备接线前，须将网关上的 232 / 485 拨码开关设置为与“预留通讯口”一致的位置。

网络连接网关可通过以太网或 Wi-Fi 连接上位机。使用 Wi-Fi 时，在配置导入后于配置页“设置”中选择网络并输入密码；Wi-Fi 密码不得写入调研表。

5配置导入

责任人：实施人员（使用厂家账号）

5.1 访问网关配置页

方式一：网关配置热点（推荐）
电脑连接 Wi-Fi IoTGW-xxxx（xxxx 为 4 位字母数字，密码见网关标签），在浏览器中访问 http://192.168.4.1。
新网关上电后自动开启热点；已配置的网关可在 5 秒内连续按 3 次复位键（或快速断电上电 3 次）开启热点。热点在 10 分钟内无设备连接时自动关闭。
方式二：局域网访问
在浏览器中访问 http://网关编号.local（如 http://jxgs001.local，编号为小写），或 http://网关 IP。
电脑启用代理软件时，须将 *.local 设置为直连。

以用户名 factory 及厂家账号密码登录。配置导入仅限厂家账号操作；客户账号 admin 仅可查看。

5.2 导入步骤

  1. 1点击顶部“采集”标签。
  2. 2在“导入设备配置”中选择本厂调研表文件（.xlsx）。
  3. 3页面显示“本网关采集的设备”列表。表中网关编号与本机一致的设备将自动选中；否则按“车间 · 设备名称 · 资产编号”手动选择。
  4. 4点击“校验”。网关检查协议、地址、数据类型等内容，并指出错误所在的工作表及行号（见 5.3）。修改调研表并保存后，重新选择文件并校验。
  5. 5校验通过后点击“导入并重启”，在确认框中核对设备、协议及点位数量后确认。网关重启后按新配置采集，页面自动返回登录页。

6现场验收

责任人：实施人员

验收项目

  • A“采集状态”显示正常
  • B各点位均有当前值，且与设备显示值一致；计数类数据应在设备动作后同步变化
  • 开关量随设备启停在 0 与 1 之间变化
  • “状态”页中上位机通道显示已连接
  • 上位机可查询到该设备（资产编号）的数据
  • 调研表中该设备的“实施状态”已更新为已上线
  • 已通过“导出 Excel”备份本网关配置，并与照片一并归档
试读采集页“试读”可按当前设备读取任意地址（厂家账号），不上报、不修改配置。点位数值与设备显示不符时，先点击该数据点带入地址，再更换类型、字序或相邻地址试读，确定正确的写法后修改调研表重新导入；厂商点位表中的地址也可逐个试读核对。
报文核查“报文”页可开启报文监视，查看网关与上位机、设备之间的原始报文；出现异常时可导出记录提交研发。

?故障排查

采集页提示常见原因排查顺序
设备无应答拨码开关位置错误、接线错误、通讯参数不一致① 检查拨码开关 232 / 485 位置；② RS485 调换 A、B，RS232 检查收发交叉及 GND；③ 核对通讯参数、站号与 PLC 设置；④ 确认设备已上电且通讯口已启用
N 个点读取失败相应点位的地址或数据类型错误与厂商点位表核对地址；确认双字、浮点数据未误选为整数
应答偶有错码（诊断页）线路干扰：线缆过长、未接地、靠近动力线连接 GND，改用屏蔽双绞线，远离变频器；条件允许时降低波特率。错码已由校验机制拦截，不会上报错误数据
连接不上设备网口设备 IP、端口错误，或不在同一网段用电脑 ping 设备 IP；确认设备端口及对应协议已开启
数据异常数据类型、倍率或字序设置错误数值相差 10 倍或 100 倍时调整倍率；数值明显异常时尝试“双字整数 / 浮点数”，或调整字序（如 CDAB）
上位机已暂停采集上位机下发了暂停命令联系上位机负责人
配置页无法打开热点已关闭，或电脑代理设置影响访问连续按 3 次复位键重新开启热点；关闭代理或将 *.local 设置为直连

问题无法解决时，在“诊断”页点击“导出诊断信息”，连同调研表及照片提交研发。

↻网关更换与配置变更

场景操作
网关故障更换在新网关上导入同一份调研表并选择同一设备。导入时提示“网关编号不一致”，确认后继续。资产编号不变，上位机数据保持连续；同时将调研表中的网关编号更新为新编号。
增加采集项在采集点位中增加行，编号顺延，不得修改已有编号；完成后重新导入。
新增同型号设备在设备清单中增加一行并填写相同的点表名称，安装网关后导入。
网关改接其他设备导入新设备的配置；停止采集时在“采集”页点击“删除配置”。
