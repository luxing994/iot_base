使用说明
  1. 填写工厂名称后，点击“新增设备”逐台录入；同型号设备可在编辑页点击“复制为新设备”，仅需修改名称和编号。
  2. 无法确认的项目选择“未知”或留空，不得估填。
  3. 照片在设备编辑页直接拍摄或从相册选择，每台设备应至少拍摄铭牌、电柜内控制器、通讯接口各一张；厂商提供的点位表、协议文档等资料可一并添加。
  4. 点击“导出调研资料”：有照片或资料时导出 .zip 资料包（内含调研表 .xlsx 及按“资产编号-类型-序号”命名的照片），否则导出调研表 .xlsx。实施人员解压后使用其中的 .xlsx 导入网关。
  5. 需继续修改时，点击“打开调研资料”选择已导出的 .zip 或 .xlsx 文件；实施人员已填写的采集点位和实施配置将保留。
  6. 数据仅保存在当前浏览器中，清除浏览器数据会丢失，请及时导出。
