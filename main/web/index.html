出厂参数客户不能修改，客户恢复出厂也不会清除。

修改网页密码

忘记网页密码时请联系厂家售后处理。

访问控制

网页使用 HTTP，从局域网访问时密码以明文传输。打开后局域网 IP 访问会被拒绝，只能连按 3 次复位键打开配置热点后访问 http://192.168.4.1。

维护

再次进入配置模式：5 秒内连续按 3 次复位键（或快速断电上电 3 次），网关会打开配置热点 10 分钟；连着局域网时也可直接访问网关 IP。

恢复出厂会清除现场参数（网络、上位机地址、网口 PLC、网页密码等）并打开配置热点；设备号、端口、热点密码等出厂参数保留。
